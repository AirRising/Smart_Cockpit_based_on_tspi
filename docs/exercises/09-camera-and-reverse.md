## 题目

### 09-01 从入口参数到一帧图像（5分）

- 输入约束：对比服务不传参 start、教程观察器 start，以及填写设备路径的管线；不实际调用任何一种。
- 任务：查出默认尺寸/帧率和观察器尺寸/帧率，画出两种源到 appsink 的路径。
- 任务：说明 NV12 两平面的组成，判断启动返回 true 是否已经证明收到非空图像。
- 学生提交物：参数对照表、两条管线图和一个首帧验收条件。
- 验收/评分点：参数 2 分，源/转换/appsink 链路 2 分，首帧条件 1 分。
- 作答边界：不要把观察器的减负设置误写成服务默认配置。

### 09-02 跨线程交付与图像所有权（5分）

- 输入约束：appsink 回调拿到一个 sample，随后 sample 与映射会释放，GUI 还没处理排队事件。
- 任务：按源码描述转换、图像保存、排队、校验、发信号的线程归属。
- 任务：解释能否直接保存外部平面指针，及当前实现是否属于 zero-copy。
- 学生提交物：线程泳道图，标出 sample/map/QImage 三种寿命。
- 验收/评分点：流线程与 QObject 线程 2 分，独立图像及寿命 2 分，拷贝性质 1 分。
- 作答边界：互斥锁或隐式共享不能作为工作线程任意调用 QWidget 的理由。

### 09-03 停止不是只释放一个指针（5分）

- 输入约束：已有一帧排队未交付，之后调用 stop，再立即 start；另考虑重复 stop。
- 任务：按当前代码列出停止步骤，解释空回调结构、generation 和空 QImage 各防什么问题。
- 任务：判断仅检查 running 或仅断开信号是否足够。
- 学生提交物：顺序清单和一个旧帧回流反例。
- 验收/评分点：清理顺序 2 分，代次与回调处理 2 分，幂等清屏/重启反例 1 分。
- 作答边界：start/stop 在服务所属线程调用，不跨线程直接操作 QTimer。

### 09-04 手算 stride、转角与检测时间（15分）

- 输入约束：NV12 为 4×4，Y stride=8，UV stride=8；两平面分别分配 4 行和 2 行，起点独立；坐标从 0 开始。
- 输入约束：求像素 (3,2) 的 Y/U/V 平面内偏移；另估算紧密 NV12 与本题含填充缓冲区的字节数。
- 输入约束：VideoWidget 宽 1000，转角依次 -900、-450、0、450、900；按源码求归一化值和轨迹水平 shift。
- 输入约束：t=0 记录启动时间，始终无帧且无 ERROR/EOS，轮询严格在 200ms 的整数倍发生，事件循环不延迟。
- 任务：完成偏移/容量表、转角表，并求第一次无帧超时检测时间；解释真实调度的不同。
- 学生提交物：完整计算过程，明确字节、度、像素与毫秒单位。
- 验收/评分点：Y/UV 偏移与容量 6 分，转角饱和/shift 5 分，检测时间及条件 4 分。
- 作答边界：平面起点由视频映射提供，不能把本题的排布假设推广为所有设备缓冲区布局。

### 09-05 实践：合成彩色 NV12 与字节布局检查（20分）

- 输入约束：仅用内存夹具，参考 4×4/stride=8 的布局；填充区设与有效像素不同的哨兵，不访问真实设备。
- 彩色输入：独立 2×2 同色块取 `(Y,U,V)=(81,90,240)` 和 `(41,240,110)`；另备黑白块，按源码 BT.601 limited-range 运算。
- 任务：实现或抽取学习副本的 CPU 转换计算，验证行寻址、UV 共享与目标行步长；比较整数像素与实际字节顺序。
- 任务：在小端条件下检查 `0xFFRRGGBB` 经 `quint32*` 写入 RGBA8888 的结果；提出一种格式一致性修正并写测试。
- 学生提交物：合成夹具/测试源、至少六条断言、红蓝块的整数值和内存字节表；不交整套摄像头实现。
- 无硬件替代：用脚本数组与小端整数打包模拟；无运行环境提交测试源和逐像素手算结果。
- 验收/评分点：stride/UV/目标步长 6 分，彩色换算与布局证据 6 分，修正方案及反例 5 分，边界标注 3 分。
- 编码约束：不引用 unmap 后的外部数据，不凭黑白测试就宣称所有颜色正确。
- 作答边界：字节布局修正仅在学习副本；真实设备色彩空间与显示链仍待验证。

### 09-06 实践：故障清屏与旧代次隔离（20分）

- 输入约束：建立假管线、虚拟时钟与排队列表；不操作真实 GStreamer 管线，也不启动显示窗口。
- 测试输入：正常首帧、EOS、ERROR、启动后一直无帧、出帧后停帧、旧帧排队后 stop、stop 后立即重启。
- 任务：实现最小生命周期模型，记录 running、generation、轮询状态、空/非空交付与 cameraError 次数。
- 任务：旧帧用 2×2 标记，新帧用 64×48 标记；重启完成后再交付旧回调，检查其是否污染新流。
- 学生提交物：测试源/脚本、至少七条事件轨迹、清屏与报错顺序，以及显式重启恢复的断言。
- 无硬件替代：纯模型是完整替代作业；若只交 Qt/GStreamer 测试源，附未运行说明和纸面预期，不要求安装运行时。
- 验收/评分点：故障与无帧检测 6 分，清理/清屏顺序 5 分，旧代次过滤 6 分，重启/重复 stop 3 分。
- 编码约束：不能用清空测试队列绕过旧 lambda 校验；也不能靠阻塞事件循环“等不到旧帧”假装通过。
- 作答边界：模型恢复必须由显式 start 驱动，不把自动重连偷偷加入原版行为说明。

### 09-07 排障：NO SIGNAL、绿线与颜色异常（15分）

- 输入约束：收到四份报告：约数秒后 NO SIGNAL 但绿线还在；黑窗伴 OpenGL context 错误；彩色图红蓝异常；重启闪回旧图。
- 任务：逐项区分采集、时间检测、像素格式、交付代次与显示环境问题，列出优先观察量。
- 任务：评审“offscreen 测试通过，因此图像比例、颜色和帧率都通过”的结论。
- 学生提交物：四行排障表与一段证据范围说明；每行附最小模型或源码检查方法。
- 验收/评分点：NO SIGNAL/轨迹含义 4 分，OpenGL/视觉边界 4 分，颜色问题 4 分，旧代次 3 分。
- 无硬件替代：用故障事件和字节夹具定位；不要求调整驱动、访问设备或创建显示会话。
- 作答边界：运行成功、非空帧到达、最终成像正确是三项不同验收。

### 09-08 综合：倒车抢占与退出后的页面（15分）

- 任务：给出“恢复最近普通页”的学习版设计和最小反例测试，不修改参考仓库。

<details><summary>参考答案与评分提示（先独立完成）</summary>

**09-01**

- 服务默认 1280×720@30；教程观察器显式采用 640×360@15，两者不能混淆。
- 空设备为 `videotestsrc pattern=ball→NV12 caps→appsink`；设备路径为 `v4l2src io-mode=4→尺寸/帧率 caps→videoconvert→NV12→appsink`。
- NV12 是 Y 平面加交错 UV 平面，每个 2×2 像素共享 U/V；start true 只代表启动请求未立即失败，还要等非空 frameReady。

**09-02**

- sample 在流线程 pull，handleSample map 后按 stride 做 CPU 转换，分配独立 QImage；unmap 后排队 lambda，随后 sample unref。
- lambda 按值捕获 image 与 generation，投递到服务的 QObject 线程；当前 main 中是 GUI 线程，校验 running/代次后才 emit frameReady。
- 不能交付失效的外部平面指针；QImage 隐式共享只影响后续共享/复制，不抹去此前分配与逐像素转换，当前不是 zero-copy。

**09-03**

- 顺序：停 timer、running=false、generation 递增、用空成员的有效回调结构撤销回调、管线 NULL、unref 并置空、时间戳清零、发空 QImage。
- 不能把回调结构指针直接传 nullptr；传有效空结构与清空 userData 是两层含义。空图让显示端进入 NO SIGNAL。
- 只检查 running 会在立即重启后误接旧帧；断开信号不撤销已排队 lambda，仍需代次校验。重复 stop 可重复发空图，接收端应允许。

**09-04**

- (3,2) 的 Y 偏移为 `2×8+3=19`；UV 行为 `2/2=1`，U 偏移 `1×8+(3/2)×2=10`，V 为 11，除法取整。
- 紧密 NV12 为 `4×4+4×2=24` 字节；含填充为 `8×4+8×2=48` 字节；不要把 UV 偏移加到 Y 指针上。
- 转角 -900/-450/0/450/900 的归一化值为 -1/-1/0/1/1，`shift=norm×1000×0.18`，得 -180/-180/0/180/180 像素。
- 轨迹在 ±450° 饱和，超过后不再增加；0 时对称。这是示意曲线，不包含车辆运动或距离标定。
- poll 间隔 200ms，无帧阈值 2500ms；2400ms 未达阈值，2600ms 首次检测到。真实事件循环延迟可能使发现更晚，不能承诺精确2500ms。

**09-05**

- 源码使用 `c=Y-16,d=U-128,e=V-128`，按整数公式计算并限幅；两彩色块应分别得到 RGB=(255,0,0) 与 (0,0,255)。
- 整数分别为 `0xFFFF0000`、`0xFF0000FF`；小端写入内存分别为 `00 00 FF FF`、`FF 00 00 FF`。
- RGBA8888 按字节解释为 R/G/B/A，前者实际成蓝、后者成红；当前小端红蓝互换问题尚未修复，黑白块无法暴露它。
- 可在学习副本保持 RGBA8888 并逐字节写 R/G/B/A，或核对并改用与 `0xAARRGGBB` 整数布局一致的 ARGB32；须补字节与通道断言。
- 断言片段（非完整测试）：`assert rgba_bytes(red_pixel) == bytes([255, 0, 0, 255])`，其中辅助函数代表学习版写入逻辑。
- stride 测试应让相邻行/色度块不同、填充区为哨兵；Y 用 j*yStride，UV 用 (j/2)*uvStride，目标用 bytesPerLine，不能全都用宽度替代。
- 正确字节仍不证明真实设备符合 BT.601 limited-range；实际色彩空间与 OpenGL 显示单列“未验证”。

**09-06**

- EOS/ERROR 的失败路径均先 stop/空图清屏，再报 cameraError；模型中一次终止事件导致一次错误，后续轮询不重复报。
- 启动时记录当前时间，所以没第一帧也能超时；出帧后停帧以最近帧时间重新计算，按下一轮 poll 检查阈值。
- 设旧帧捕获代次 g，stop 后为 g+1；当前 start 内还会调用 stop，因此重启后可能再递增，测试应要求“不同于 g”而非机械固定加一。
- 排队旧 2×2 即使在 running 再次为 true 时也不得交付；显式重启后的新 64×48 允许交付，不用删除队列来偷换校验。
- stop 后空图至少一次，重复 stop 可再空图；时间戳清零不代表 lastFrameAgeMs 返回 0，需结合 isRunning 判断。
- 无自动重连，只有显式 start 恢复；running 时再 start 当前直接返回 true，不热切参数，换参数要先 stop。

**09-07**

- NO SIGNAL 后仍有绿线符合 paintGL 顺序：空图提示之后还画轨迹；绿线不能证明采集正常。先查 cameraError、running、最近帧年龄。
- OpenGL context 错误属于显示环境证据，非空图模型通过不能排除它；offscreen/GUILESS 测试不验最终颜色、比例或帧率。
- 红蓝异常先核对 NV12 平面、stride、矩阵与 QImage 字节布局，用彩色块证伪；当前已知整数写 RGBA8888 问题应单列。
- 旧画面闪回先查捕获代次、交付校验及空图是否送达，不能仅靠 mutex 或 running。
- 当前按宽计算高度再求交的目标矩形也不能保证所有比例都居中等比留黑；显示验收仍需后续桌面/板端证据。

**09-08**

- Media 后集合为 {Media:Normal}；Climate 后保留两项且当前为 Climate；倒车加入 Urgent 并抢占。
- Instrument/Normal 低于当前 Urgent，被拒且不加入集合；dismiss 倒车后剩 Media、Climate 两个 Normal。
- 最高优先级相同且遍历 QHash，没有最近访问顺序，所以可能选 Media 或 Climate，不能保证回到紧邻上一页；m_previous 不是历史栈。
- 只有一个 Media 活跃请求的对照分支返回 Media；简单用例通过不证明多普通页返回策略。
- main 启动时就 start 摄像头，倒车只是 reverseChanged→Urgent/dismiss 页面切换；退出不停止常驻采集，也没有由抢占触发的音频暂停策略。
- 故障后会停止而非自动重连；学习版可用独立最近普通页记录/序号或清理旧请求，并测试 Media→Climate→R→退出稳定回 Climate。
- 最终结论区分帧/代次逻辑、页面优先级与视觉/真实设备：前两项可用模型验，后者仍“未验证”，示意轨迹也未经标定。
